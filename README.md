# Pinjemin-mobile
Aplikasi mobile yang memfasilitasi mahasiswa Universitas Indonesia dalam meminjamkan atau menyewakan barang kebutuhan kuliah, organisasi, dan kos guna mengurangi penumpukan barang jarang terpakai dan pembelian berlebih. Proyek ini dibuat sebagai penerapan pengembangan web Django dan aplikasi Flutter dalam tema *Sustainable Living*.

## Tema Proyek

* **Tema Utama:** Sustainable Living
* **Subtema:** Collaborative Consumption & Circular Economy
